How a change goes live

Nothing you save is public straight away. Every edit is checked by an approver first, so there's no way to break the site by accident.

1You edit

In the editor, make the change and press Save. It sits in Drafts until you move it to In review.

2An approver checks it

The President or Secretary gets the change as a pull request on GitHub and approves it. Money and link changes also need the Treasurer.

3It goes live

Press Publish (or merge on GitHub). Netlify rebuilds the site and the change is up within a minute.
